# FilmYears — UI 生成提示词（适用于 Stitch / Midjourney / DALL·E 等 AI UI 生成工具）

## 全局设计语言

**品牌**：FilmYears — 胶片年轮时间可视化记忆 App（iOS，海外市场）
**视觉风格**：黑暗胶片美学，暗房氛围，温暖琥珀色点缀
**基础背景色**：`#0d0d0d`（极黑）至 `#1a1a1a`（深灰）
**强调色**：`#c8963e`（暖琥珀金）
**文字色阶**：`#f0ece4`（暖白主文）→ `#a09a92`（次要）→ `#6b6660`（辅助）
**字体**：SF Pro Display / -apple-system, 无衬线
**圆角体系**：14px 卡片圆角，8px 小圆角
**设计哲学**：只回望已经活过的时光，不渲染未来、不做生命倒计时焦虑叙事

## 屏幕 1：Onboarding 首次启动引导页

**布局**：居中布局，深色渐变背景（径向渐变 `#1a1510` → `#0d0d0d`）

### 元素清单
1. **顶部图标**：🎞️ 胶片图标（48px, 暖琥珀色 sepia 滤镜）
2. **App 标题**："FilmYears"（36px, 粗体 800, 暖琥珀色）
3. **副标题**："每一年是一卷胶卷，每一天是一张胶片帧"（15px, 次要文字色）
4. **提示文字**："你的出生日期是？"（13px, 次要文字色）
5. **日期选择器**：三个字段横向排列（年/月/日），每个字段为焦点态带琥珀色边框的深色输入框

6. **主按钮**："开始我的胶片年轮"（暖琥珀色背景 `#c8963e`，深色文字，圆角 14px，悬停微放大）

### 状态
- **初始**：按钮可点击状态，日期为默认值
- **交互**：选择日期时字段边框高亮变琥珀色

## 设计约束与避坑指南

1. ❌ 不要用米色/沙色/奶油色背景
2. ❌ 不要用紫色→蓝色对角线渐变
3. ❌ 不要用弹跳/弹性缓动曲线
4. ❌ 不要用表情符号作为严肃产品的图标
5. ❌ 不要展示未来日期/未来胶卷/生命倒计时
6. ❌ 不要在浅色背景上使用低对比度灰色文字
7. ✅ 遵循 WCAG AA 对比度标准
8. ✅ 使用真实的字体层级（从 11px 到 36px 的完整字阶）
9. ✅ 保持一致的间距节奏（4px 基准网格）
10. ✅ 每个视图只有一个清晰视觉焦点
11. ✅ 深色背景上确保文字可读性
